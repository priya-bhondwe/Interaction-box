# **Interactive Product Boxes – Front-End Developer Task**

This project is a submission for the **Front-End Technical Support Task**, demonstrating skills in **HTML**, **CSS (no frameworks)**, and **vanilla JavaScript**.
The goal was to recreate a set of **interactive product option boxes**, matching the provided **Figma design** and **example video** as closely as possible.

---

## 🚀 **Project Overview**

The page contains **three interactive product boxes**:

* **Box 1** – 1 Unit + 10% Off
* **Box 2** – 2 Units + 20% Off + *“Most Popular”* ribbon
* **Box 3** – 3 Units + 30% Off

Each box behaves as follows:

### ✔ Click to Expand

* Only one box expands at a time
* Clicking another box collapses the previously expanded one
* Expanded view shows:

  * Size options
  * Color options
  * Free Delivery
  * Add to Cart button

### ✔ Interactive Chips

* Size and Color chips are selectable
* Active chip highlights using custom CSS
* No third-party UI libraries used

### ✔ Vanilla JavaScript

* Handles expansion/collapse logic
* Handles chip selection
* Handles “Add to Cart” alert action button
* Handles keyboard accessibility (`Enter` / `Space` to open a box)
